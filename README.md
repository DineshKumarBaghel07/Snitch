# Snitch - E-Commerce Platform

## 🚀 Overview

Snitch is a modern full-stack e-commerce application built using the MERN stack.
It provides secure authentication, role-based authorization, Google login, product management, cart functionality, and an admin dashboard.

---

# ✨ Features

## 🔐 Authentication
- JWT Authentication
- Secure Login & Registration
- Protected Routes
- Persistent User Sessions

## 🌐 Google Authentication
- Google OAuth Login
- One-click Sign In

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/DineshKumarBaghel07/Snitch.git
```

---

## 2. Install Dependencies

### Frontend

```bash
cd Frontend
npm install
```

### Backend

```bash
cd Backend
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=3000

MONGO_URI=your_mongodb_url

JWT_SECRET=your_jwt_secret

GOOGLE_CLIENT_ID=your_google_client_id

GOOGLE_CLIENT_SECRET=your_google_client_secret
```

---

# ▶️ Run Project

## Backend

```bash
npm run dev
```

## Frontend

```bash
npm run dev
```
