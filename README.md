Snitch - E-Commerce Platform
🚀 Overview

Snitch is a modern full-stack e-commerce application built with the MERN stack.
It provides secure authentication, role-based authorization, product management, cart functionality, and an admin dashboard.

⚙️ Installation
1. Clone Repository
git clone https://github.com/your-username/snitch.git
2. Install Dependencies
Frontend
cd Frontend
npm install
Backend
cd Backend
npm install
🔑 Environment Variables

Create .env file inside backend folder.

PORT=5000

MONGO_URI=your_mongodb_url

JWT_SECRET=your_jwt_secret

GOOGLE_CLIENT_ID=your_google_client_id

GOOGLE_CLIENT_SECRET=your_google_client_secret
▶️ Run Project
Backend
npm run dev
Frontend
npm run dev
